# 🚢 振华连连看 (Zhenhua LinkGame)

基于 **Python + Pygame** 开发，并通过 **Pygbag** 编译为 WebAssembly 的跨平台连连看小游戏。支持电脑端鼠标操作与手机端单指触控，无需安装任何环境，打开网页即玩。

## 🎮 在线试玩

👉 **[点击这里，立即开玩](https://ai-der.github.io/zhenhua_linkgame/)**

- 📱 **手机端**：使用手机浏览器打开（支持横屏体验），单指点击即可轻松消除。
- 💻 **电脑端**：使用鼠标左键点击操作。

## ✨ 游戏特性

- **极简部署**：使用 Pygbag 将 Python 代码打包为纯前端网页，部署在 GitHub Pages。
- **双端适配**：重构了事件循环，完美兼容 PC 端的 `鼠标点击` 与移动端的 `单指触摸`。
- **动态资源加载**：支持自定义图片，游戏会根据 `assets` 文件夹中的图片数量自动调整图案种类。
- **高清渲染**：去除了浏览器的默认平滑模糊，并加入圆角遮罩（Mask），解决图片边缘毛刺。
- **防卡死机制**：本地化修复了 `browserfs.min.js` 的 404 问题，解决了网页加载卡死或黑屏的现象。
- **智能提示**：内置 BFS 寻路算法，实时高亮提示可消除的方块及连线路径。

## 🕹️ 玩法说明

| 操作 | 说明 |
| :--- | :--- |
| **点选方块** | 选中两个相同图案的方块，若它们之间连线的转弯数不超过 2 次，即可消除。 |
| **重排** | 当场上无解时，点击按钮打乱剩余方块。 |
| **提示** | 点击后高亮显示一对可以消除的方块及其连线。 |
| **新游戏** | 随时重新开始对局。 |
| *快捷键* | 电脑端支持按 `R` 重排，`H` 提示，`N` 新游戏，`Esc` 退出。 |
